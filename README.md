# D&D Combat Simulator

**Overview**
A console-based Dungeons & Dragons combat simulator written in C. This project was developed as an academic assignment at ELTE to practice low-level programming and data processing

**Core Functionality**
* Simulates turn-based RPG combat mechanics and randomized dice rolls
* Reads and parses character statistics and encounter data from external text files
* Manages game state and user interaction through a command-line interface

**How to Run**
1. Clone the repository: `git clone [repository-link]`
2. Compile: `gcc main.c DnD.c -o dnd_sim`
3. Execute: `./dnd_sim`
